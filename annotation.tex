\Title{Автоматическая оценка русскоязычных ответов учащихся\\с использованием современных моделей естественного языка}
\Author{Студента}{Копнина Владислава Николаевича}
\Group{ИВТ-42БО}
\Kafedra{Компьютерных сетей}
\Chief{Лагутина Н.\,С.}{к.\,ф.-м.\,н., доцент}
\Actuality{Автоматическая оценка коротких открытых ответов (ASAG) является актуальной задачей для образовательных систем, особенно для русского языка, для которого наблюдается острый дефицит как размеченных корпусов, так и систематических исследований.}
\Goal{Разработка, сравнительный анализ и внедрение методов автоматической классификации русскоязычных коротких ответов учащихся по степени их соответствия эталонному ответу. Для достижения цели решены следующие задачи:
\begin{itemize}
    \item сбор и экспертная разметка корпусов ответов;
    \item разработка экспериментального фреймворка;
    \item проведение сравнительного анализа комбинаций моделей и классификаторов;
    \item исследование влияния дисбаланса классов и разработка метода аугментации;
    \item внедрение оптимальной конфигурации в платформу <<Абрис>>.
\end{itemize}
}
\Content{В работе рассмотрены 11 предобученных языковых моделей (энкодерных, декодерных и энкодер-декодерных) и 7 классификаторов, включая авторский центроидный классификатор. Эксперименты проводились в бинарном, тернарном и кватернарном сценариях классификации с использованием нескольких стратегий валидации (стратифицированная кросс-валидация, LOCO, LSCO). Разработан метод аугментации данных на основе рекомбинации ответов. Создан модуль автоматической проверки для системы <<Абрис>>, апробированный в реальном учебном процессе.}
\Result{Бинарная классификация решается с F-мерой до 0.98 и пригодна для практического использования. Тернарная классификация с применением аугментации достигает F-меры 0.82. Разработанный фреймворк зарегистрирован в Роспатенте. Результаты опубликованы в семи научных работах, включая статью в журнале <<Труды ИСП РАН>>.}
